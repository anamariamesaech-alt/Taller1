# Taller básico de Python

## Descripción

Este taller contiene una serie de ejercicios prácticos desarrollados en Python con el objetivo de fortalecer los conocimientos básicos de programación mediante el uso de variables, condicionales, listas y ciclos.

## Temas trabajados

* **Variables:** almacenamiento de datos.
* **Condicionales:** toma de decisiones mediante `if`, `elif` y `else`.
* **Listas:** almacenamiento y manipulación de colecciones de datos.
* **Ciclos:** repetición de instrucciones mediante estructuras como `for` y `while`.

## Ejercicios

### 1. Descuentos según la compra

**Autor:** Ana María Mesa

Solicitar el valor de una compra y aplicar un descuento según el monto:

* 5 % para compras iguales o superiores a $100.000.
* 10 % para compras iguales o superiores a $300.000.
* 15 % para compras iguales o superiores a $500.000.

Al finalizar, mostrar el valor total de la compra después de aplicar el descuento correspondiente.

### 2. Serie Fibonacci

**Autor:** Laura Ulloa

Solicitar al usuario la cantidad de términos que desea visualizar y generar la serie de Fibonacci, comenzando por 0 y 1.

### 3. Mayor y menor de una lista

**Autor:** Mariana Cardona

Solicitar 10 números al usuario, almacenarlos en una lista y determinar cuál es el mayor y cuál es el menor, sin utilizar las funciones integradas `max()` ni `min()`.

### 4. Eliminar números repetidos

**Autor:** Sebastián Madrigal

Crear una lista que contenga números repetidos y generar una segunda lista sin elementos duplicados, sin utilizar la función `set()`.

## Tecnologías utilizadas

* Python 3
* Editor de código: Visual Studio Code

## Ejecución

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Verificar que Python esté instalado.
4. Ejecutar el archivo `.py` correspondiente a cada ejercicio desde la terminal.

Ejemplo:

```bash
python nombre_archivo.py
```

## Objetivo del taller

Practicar los fundamentos de Python mediante la resolución de problemas sencillos, fortaleciendo la lógica de programación y el manejo de estructuras básicas del lenguaje.
